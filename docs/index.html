How automatic readings work

A scheduled job on GitHub logs in to your Alfa Connect account once a day, reads the odometer and saves it to docs/readings.json. This page loads that file every time you open it. Readings you type in by hand are kept on this phone and are used alongside the automatic ones.

Your lease details are stored on this phone. To change the starting values for a fresh install, edit docs/config.json in the repository.
